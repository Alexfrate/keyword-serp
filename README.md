# Ricerca keyword

Metodo per scegliere query con domanda vera e pagina 1 organica più debole, poi il tipo di pagina. Vale su WordPress, Shopify, Next, Webflow, HTML. Non promette posizioni.

La skill sta in `SKILL.md`. I dettagli in `references/`.

## Strumenti

| Uso | Link |
|---|---|
| Browser, alternativa ai pannelli | https://github.com/browser-use/browser-use |
| Pagine Elementor su WordPress | https://github.com/aguaitech/Elementor-MCP |
| WordPress (REST, application password: Yoast, redirect, post) | https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/#application-passwords |
| MCP WordPress generico, se non è Elementor | https://github.com/docdyhr/mcp-wordpress |
| Volumi | https://ads.google.com/home/tools/keyword-planner/ · https://github.com/ncosentino/google-keyword-planner-mcp |
| Search Console | https://search.google.com/search-console · https://github.com/chrishart0/searchconsole-mcp |
| Bing (ChatGPT e Copilot) | https://www.bing.com/webmasters · https://github.com/idowebid/bing-webmaster-mcp |

Su un sito Elementor le pagine si pubblicano con Elementor-MCP (`npx elementor-mcp`). Il resto di WordPress passa dalla REST con una application password. browser-use copre Planner, SERP, Search Console e Bing se l'MCP non c'è. «Richiedi indicizzazione» si preme solo dal browser.

Niente password, chiavi o token in questo repo.
